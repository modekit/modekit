# Spinner

Spinner communicates that an operation is in progress. `MkSpinner` inherits the current text color,
supports the same size scale as Button, and disables its animation when reduced motion is requested.

## Usage

### Size

Use the `size` prop to fit the indicator to its context. It defaults to `md`.

<ComponentPreview name="spinner/SpinnerSize" />

Available sizes are `xs`, `sm`, `md`, and `lg`.

## API

### Props

| Prop   | Type                           | Default | Description                                          |
| ------ | ------------------------------ | ------- | ---------------------------------------------------- |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'md'`  | Sets the indicator dimensions.                       |
| `ui`   | `{ base?: ModeKitClassValue }` | —       | Adds or overrides classes for this Spinner instance. |

All other native span attributes and classes are forwarded to the underlying `<span>`.

## Styling

Spinner uses `currentColor`, so set a text color on the component or an ancestor to control its
appearance. Local `ui.base`, global Spinner configuration, and native `class` resolve in that order
after the built-in recipe; later classes win conflicts.

```vue
<MkSpinner size="lg" class="text-destructive" />
```

Global configuration can override base classes, each size, and the default size:

```ts
app.use(
  createModeKit({
    ui: {
      spinner: {
        base: 'text-primary',
        variants: {
          size: {
            lg: 'size-7',
          },
        },
        defaultVariants: {
          size: 'lg',
        },
      },
    },
  }),
)
```

ModeKit ships the utilities used by the built-in recipe. Additional Tailwind utility names supplied
by an application must be generated by that application's Tailwind build.

## Accessibility

Standalone Spinner renders `role="status"` and `aria-label="Loading"` by default. Override the label
when a more specific operation name is useful. Set `aria-hidden="true"` when the surrounding control
already communicates the busy state; this removes the default status role and label. Button does
this automatically for its built-in Spinner because Button exposes `aria-busy` and keeps its label
visible.
